Installer CINOZA

Android TV, Google TV, tablettes et mobiles — Android 8.0 ou plus récent

CINOZA n'est pas distribuée sur Google Play : elle s'installe à partir du fichier APK publié sur ce site. L'installation prend quelques minutes.

CINOZA est un lecteur multimédia. Elle ne fournit aucune chaîne, aucun film, aucune série ni aucun abonnement IPTV : vous utilisez vos propres sources.

  1. Récupérer le fichier APK

    Depuis la section Installer CINOZA, téléchargez le fichier sur votre ordinateur ou votre téléphone.

    CINOZA se télécharge uniquement sur cinoza.fr. Un fichier obtenu ailleurs (messagerie, forum, autre site) n'est pas officiel et pourrait dérober vos identifiants IPTV : ne l'installez pas.

    Pour vérifier qu'il est intact (facultatif), comparez son empreinte SHA-256 avec celle affichée sur le site :

    • Windows (PowerShell) : Get-FileHash fusion-tv.apk
    • macOS ou Linux : shasum -a 256 fusion-tv.apk

    Pour vérifier qu'il est bien signé par CINOZA, comparez l'empreinte de son certificat de signature avec celle-ci (sur Android : application « Package Info » ; sur ordinateur : apksigner verify --print-certs fusion-tv.apk) :

    0D:AD:98:66:A2:3F:52:40:DA:49:B4:9F:B3:B8:06:6E:13:50:91:73:82:4B:B7:AD:1A:00:26:B7:1B:5F:C5:2E

    Cette empreinte ne change pas d'une version à l'autre. Si elle est différente, le fichier n'est pas officiel.

  2. Transférer le fichier sur l'appareil

    • Avec l'application Downloader (le plus simple) : installez Downloader depuis le Play Store du téléviseur, ouvrez-la et saisissez le code 9685240, puis « Go » ; le téléchargement démarre, puis l'installation est proposée. Ce code est le seul code officiel de CINOZA.
    • Avec le navigateur du téléviseur : saisissez l'adresse cinoza.fr/fusion-tv.apk.
    • Avec une clé USB : copiez le fichier sur la clé, branchez-la au téléviseur, puis ouvrez-le avec un gestionnaire de fichiers.
    • Depuis votre téléphone : utilisez une application d'envoi de fichiers vers le téléviseur, installée sur les deux appareils.
    • Sur une tablette ou un mobile Android : rien à transférer. Ouvrez cinoza.fr dans le navigateur, touchez « Télécharger CINOZA (.APK) », puis ouvrez le fichier téléchargé : Android propose l'installation.

  3. Autoriser l'installation, si nécessaire

    Au premier essai, Android peut bloquer l'installation d'une application externe. Il propose alors souvent d'ouvrir directement le réglage concerné. Sinon :

    • Android TV : Paramètres › Applications › Sécurité et restrictions › Sources inconnues, puis autorisez l'application qui ouvre l'APK (gestionnaire de fichiers ou application de téléchargement).
    • Tablette ou mobile : Android propose « Paramètres » : autorisez le navigateur à installer des applications inconnues, puis revenez en arrière pour terminer l'installation.
    • Google TV : activez d'abord le mode développeur (Paramètres › Système › À propos, appuyez sept fois sur « Build du système d'exploitation Android TV »), puis Paramètres › Applications › Sécurité et restrictions › Sources inconnues.

    Les intitulés peuvent varier selon le modèle. Une fois CINOZA installée, vous pouvez retirer cette autorisation.

  4. Lancer CINOZA

    Ouvrez le fichier APK, choisissez « Installer », puis « Ouvrir ». Ensuite, CINOZA se trouve dans la liste des applications du téléviseur.

    Pour une nouvelle version, refaites la même installation : vos sources, profils, favoris et historique sont conservés.

  5. Activer votre accès CINOZA Access

    Au premier lancement, l'écran CINOZA Access s'affiche. Pendant la bêta gratuite, l'accès fonctionne ainsi :

    • « Commencer mon essai gratuit » : ouvre une période initiale de 7 jours (un essai par appareil).
    • « Se connecter à un compte existant » : le téléviseur affiche un code valable 15 minutes. Dès que l'association est validée, il s'ouvre automatiquement.
    • Tablette ou mobile : sur le téléviseur, Paramètres › CINOZA Access › « Ajouter mon mobile ou ma tablette » affiche un code ; saisissez-le sur la tablette ou le mobile (« J'ai CINOZA sur mon téléviseur ») : l'appareil utilise le même accès.
    • À la fin de la période : « Demander une prolongation gratuite » envoie votre demande. Elle est examinée par l'administrateur de la bêta.

    Aucun paiement n'est demandé pendant la bêta. Pour rejoindre les testeurs, écrivez à contact@cinoza.fr.

  6. Ajouter vos sources

    Dans Paramètres › Abonnements & sources, choisissez « Ajouter une source » et renseignez votre playlist M3U ou votre compte Xtream.
