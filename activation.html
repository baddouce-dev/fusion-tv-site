Licence FUSION TV

Activer votre licence

Un code de 16 caractères, saisi une fois sur chaque appareil. L'activation se fait toujours en ligne, auprès du service FUSION Access. Disponible à l'ouverture des ventes.

  1. Installez FUSION TV

    Sur votre téléviseur Android TV ou Google TV, votre tablette ou votre smartphone Android, depuis la page Télécharger.

  2. Saisissez votre code

    Au premier lancement, choisissez « J'ai un code de licence », puis saisissez les 16 caractères (par exemple XXXX-XXXX-XXXX-XXXX). Les tirets s'ajoutent tout seuls ; une faute de frappe est signalée avant tout envoi.

  3. Vérifiez puis confirmez

    « Vérifier le code » affiche ce que fera le code — durée, dates, appareil — sans rien utiliser. Vous confirmez ensuite l'activation.

  4. Ajoutez vos autres appareils

    Saisissez le même code sur votre téléphone et votre tablette : chaque licence accepte un téléviseur, un téléphone et une tablette, avec une seule lecture à la fois.

Renouveler

Dans Paramètres › FUSION Access (téléviseur, tablette) ou Plus › Mon compte (smartphone), choisissez « Ajouter un code ». Un code de la même formule ajoute 12 mois après l'échéance de votre licence : aucun jour n'est perdu.

Un code d'une autre formule prend effet à l'échéance de la licence en cours ; l'application vous l'annonce et vous demande de le confirmer avant de l'enregistrer.

Changer d'appareil

Nouveau téléviseur, téléphone remplacé ? Saisissez le code de la licence sur le nouvel appareil. Si la licence a déjà un appareil de ce type, une demande de changement d'appareil est envoyée : après validation par l'assistance FUSION TV, le nouvel appareil remplace l'ancien.

Si le code est refusé

  • Code mal saisi : vérifiez les 16 caractères ; les lettres I, L, O et les chiffres 0 et 1 n'existent pas dans les codes.
  • Code inconnu ou déjà utilisé : un code ne sert qu'à une seule licence. Contactez l'assistance si vous pensez à une erreur.
  • Service injoignable : un nouveau code ne s'active qu'en ligne. Réessayez une fois connecté.
  • Trop d'essais : la saisie est suspendue un moment, par sécurité.

Conservez vos codes : ils ne sont affichés qu'une seule fois, à l'achat.
